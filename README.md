WHAT PROJECT IS ALL ABOUT -----------
Expense Tracker with QR Code Scanner is a smart financial management application that helps users track their daily income, expenses, and digital payments in one 
place. The application allows users to add and manage transactions, monitor spending patterns, and maintain a complete payment history. It also includes a QR code
scanner feature that enables quick and secure payments by scanning QR codes, making transactions faster and more convenient. The project improves money management,
reduces manual calculation efforts, saves time, and provides users with better control over their finances through an easy-to-use and user-friendly interface.
